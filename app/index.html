UCAS API Configuration

The UCAS search uses Algolia. Enter the credentials found by the setup script, or get them manually from Chrome DevTools while on the UCAS clearing search page.

How to find these manually:
1. Open the UCAS clearing search in Chrome
2. DevTools (F12) → Network → filter by "algolia"
3. Wait for a search to fire, click the request
4. Copy X-Algolia-Application-Id and X-Algolia-API-Key headers
